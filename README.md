# 🐍 Snake Game — Jogo da Cobrinha

Um jogo inspirado no clássico Snake, desenvolvido para navegador com tecnologias web. O objetivo é controlar a cobrinha, coletar alimentos, aumentar seu tamanho e conquistar a maior pontuação possível! 🎮

## 📋 Sobre o Projeto

O Snake Game é um projeto de desenvolvimento Front-End que utiliza tecnologias nativas da web para criar uma experiência de jogo interativa, com interface visual e controles intuitivos.

O projeto foi planejado para funcionar diretamente no navegador, sem necessidade de instalar bibliotecas, frameworks ou servidores externos.

## 🚀 Tecnologias Utilizadas

- 🏗️ HTML5: estrutura da página e organização dos elementos do jogo.
- 🎨 CSS3: estilização da interface, cores, layout e apresentação visual.
- ⚡ JavaScript (Vanilla JS): implementação da lógica do jogo, movimentação da cobrinha, detecção de colisões e gerenciamento da pontuação.
- 🖌️ Canvas HTML5: recurso utilizado para desenhar e atualizar os elementos gráficos do jogo, como a cobrinha e os alimentos.

### 💡 Por que utilizar essas tecnologias?

A combinação de HTML5, CSS3 e JavaScript permite desenvolver jogos leves e interativos que funcionam diretamente no navegador, sem depender de ferramentas externas.

## 🎯 Objetivo do Jogo

Controle a cobrinha para coletar os alimentos espalhados pelo cenário. A cada alimento consumido, a cobrinha cresce, tornando o desafio cada vez maior.

O objetivo é conseguir a maior pontuação possível sem colidir com as paredes ou com o próprio corpo da cobrinha, conforme as regras implementadas no jogo.

## 🕹️ Como Jogar

1. 🌐 Abra o arquivo `index.html` em um navegador moderno.
2. ▶️ Inicie a partida utilizando o controle de início disponível na interface.
3. ⬆️⬇️⬅️➡️ Controle a direção da cobrinha utilizando as teclas direcionais do teclado.
4. 🍎 Colete os alimentos para aumentar o tamanho da cobrinha e acumular pontos.
5. 🧠 Planeje seus movimentos para evitar colisões.
6. 🏆 Tente alcançar sua maior pontuação!
